# Atividade 1 — NumPy e Series

O notebook `atividade1_resolvida.ipynb` continua o material da aula e responde o mini exercício do final. Não usa DataFrame.

## Execução

Na raiz do repositório, com as bibliotecas de `requirements.txt` instaladas:

```powershell
python -m jupyter nbconvert --to notebook --execute --inplace "etapa_3/01_numpy_series/atividade1_resolvida.ipynb"
```

Também é possível abrir o arquivo no Jupyter e rodar todas as células.
