# Streamlit — vendas de carros

`app.py` adapta o caixa de supermercado para um catálogo de carros. Os preços são didáticos. O pagamento é simulado e não movimenta dinheiro.

`st.session_state` guarda o carrinho entre reexecuções da mesma sessão. Não é um banco e não promete que o carrinho continue depois de fechar o navegador.

Na raiz do repositório:

```powershell
python -m streamlit run etapa_3/08_streamlit_carros/app.py
```
